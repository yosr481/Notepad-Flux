This is the last gate before v1.4.0 is tagged. Unit tests, lint, the Electron smoke test and Claude's code review are already done. Run every test below on the installed build, mark each Pass / Fail / Skip, then press Copy results and paste the text back to Claude. A Fail blocks the release. Your ticks are saved in this browser only.

Before you start

Install the QA build (it replaces any installed Notepad Flux; your saved session in ~/.config/notepad-flux is kept):

cd ~/Documents/LifeOS/05-Utilities/Notepad_Flux
sudo apt install ./release/"Notepad Flux-1.4.0-qa.1-linux-amd64.deb"

Package file: Notepad Flux-1.4.0-qa.1-linux-amd64.deb. If you would rather not install it, the Notepad Flux-1.4.0-qa.1-linux-x86_64.AppImage in the same folder runs without installing, but test A2 (dock icon) needs the .deb.

Keep the session log open in a second terminal. Every test below names the line it should add:

tail -f ~/.config/notepad-flux/logs/main.log

The log holds file paths and outcomes, never file content. Test files are in ~/Documents/notepad-flux-qa/. crlf-real.md, readonly.md (mode 444), moved-me.md and gone-soon.md were created for this run.

Expected noise: with the -qa.1 version the update check logs No published versions on GitHub. That's because a pre-release version looks for pre-release builds on GitHub. Ignore it; the real 1.4.0 build checks the normal channel.

A · Install & launch

  1. A1

    Launch Notepad Flux from the app grid.

    Splash, then the main window. No white flash if the system is in dark mode. Status bar shows version 1.4.0-qa.1.

    start block with version: '1.4.0-qa.1', packaged: true.

  2. A2

    Look at the dock / dash while the app runs. In a terminal: xprop WM_CLASS, then click the Notepad Flux window.

    Real Notepad Flux icon (not a generic gear). WM_CLASS mentions notepad-flux.

  3. A3

    Read the start block in the log.

    safeStorage: true and safeStorageBackend: 'gnome_libsecret', meaning the session key is in the system keyring.

  4. A4

    With the app open, launch it again from the app grid.

    The existing window comes to the front. No second window, no second start block in the log.

  5. A5

    Use the title-bar minimise / maximise / close buttons (restart the app after close).

    Native Linux window buttons are present and all three work.

B · Open & save

  1. B1

    Ctrl+O and pick basic.md.

    The picker offers Text and All Files filters. The file opens in a new tab.

    open: picked + path.

  2. B2

    Type a line in basic.md, then Ctrl+S.

    Saved in place, no dialog. The dirty mark clears. cat the file and check that the line is there.

    save: wrote + path + char count.

  3. B3

    Ctrl+Shift+S, then save as subdir/copy.md.

    The dialog opens in the folder you last used. The tab now points to copy.md.

    save-as: picked then save: wrote.

  4. B4

    Ctrl+N, type text, Ctrl+S.

    A new tab opens the Save As dialog (it has no file yet).

  5. B5

    Ctrl+O, switch the filter to All Files, and pick binary.bin. Repeat with random.bin.

    A toast says Not a text file.. No tab opens, and no garbled text appears.

    [error] line naming read-file.

  6. B6

    Open empty.md, then spaced ünïcode name.md. Edit the second file and save it.

    Both open. The file with the unicode name saves in place, and its tab title is correct.

  7. B7

    Open shadow-symlink.md (it links to /etc/shadow).

    A toast with a reason (Permission denied.). The app keeps working, and opening basic.md afterwards still works.

  8. B8

    Open readonly.md, type something, Ctrl+S.

    A toast with a reason (Permission denied.). The text you typed stays in the tab, which stays dirty.

  9. B9

    Open crlf-real.md. Check the status bar. Add a line, save, then run file ~/Documents/notepad-flux-qa/crlf-real.md.

    The status bar shows CRLF and UTF-8. file still reports CRLF line terminators after the save. Opening basic.md shows LF.

  10. B10

    Drag basic1.md from the Files app onto the editor.

    It opens as a new tab. The file's text is not pasted into the current tab.

    open: dropped + path.

  11. B12

    With crlf-real.md open, Ctrl+Shift+S to crlf-copy.md, then run file on the copy.

    The copy also has CRLF line terminators. Save As keeps the line ending, like Save.

  12. B11

    Open large.md (1.3 MB). Scroll to the end, and type near the end.

    It opens in a few seconds. Scrolling and typing stay responsive.

  1. D1

  2. D2

  3. D9

  4. D3

  6. D5

    No output, meaning no leftover process.

E · Log sanity

  1. E1

    Run grep -c '\[error\]' ~/.config/notepad-flux/logs/main.log and read each error.

    Every error matches something you did on purpose (B5, B7, B8, D4, D5) or is the known update-check noise. Anything else is a Fail; note it.

  2. E2

    Search the log for a word you typed into a file (for example, the line from B2).

    No matches. File content must never reach the log.

  3. E3

    Run cat ~/.config/notepad-flux/authorized-paths.json.

    It lists only files you opened, saved or dropped during this run. It has no folders and no paths you never touched.
